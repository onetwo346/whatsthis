# Enhanced AI Recognition Setup Guide

## What's New? 🚀

Your "What Is This?" app now features **advanced AI-powered recognition** using Google's Gemini Vision API!

### Capabilities

With the Gemini API enabled, you can now scan and identify:

- **Specific animal breeds** - "Golden Retriever" instead of just "Dog"
- **Product brands** - "McDonald's Big Mac Box" instead of just "Food Container"
- **TV shows/movies** - Identifies what's playing on screens
- **Specific plant/tree species** - "Oak Tree (Quercus robur)" instead of just "Tree"
- **Brand-specific items** - Recognizes logos, packaging, and branded products
- **And much more with extreme detail!**

## Setup Instructions

### Step 1: Get Your Free Gemini API Key

1. Visit: https://aistudio.google.com/app/apikey
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the API key (starts with "AIza...")

### Step 2: Add API Key to the App

1. Open the app and tap **ENTER**
2. Tap the **☰** (menu) button in the top right
3. Tap the **⚙️** (settings) button
4. Paste your API key in the "Gemini API Key" field
5. Tap **Save Key**

### Step 3: Start Scanning!

Now when you scan objects, the app will use advanced AI to provide:
- Extremely specific identification
- Detailed descriptions
- Accurate categorization
- Relevant warnings and information

## How It Works

### Without API Key (Basic Mode)
- Uses COCO-SSD model (offline)
- Detects 80 common object categories
- Generic identification (e.g., "Dog", "Car", "Tree")
- Works offline

### With API Key (Advanced Mode)
- Uses Google Gemini Vision AI
- Identifies thousands of specific objects
- Detailed recognition (e.g., "Golden Retriever", "2023 Tesla Model 3")
- Requires internet connection
- Free tier: 15 requests per minute

## Privacy & Security

- Your API key is stored locally in your browser
- Images are sent to Google's Gemini API for analysis
- No data is stored on our servers
- You can delete your API key anytime in settings

## Troubleshooting

### "Invalid API key" error
- Make sure your API key starts with "AIza"
- Verify you copied the entire key
- Check that the key is active in Google AI Studio

### "API rate limit reached"
- Free tier allows 15 requests per minute
- Wait a minute and try again
- Consider upgrading your Gemini API plan

### Falls back to basic detection
- Check your internet connection
- Verify your API key is saved correctly
- The app automatically uses basic mode if Gemini fails

## Tips for Best Results

1. **Good lighting** - Ensure the object is well-lit
2. **Clear view** - Point camera directly at the object
3. **Close enough** - Get close enough to see details
4. **Steady camera** - Hold still while scanning
5. **Unique features** - Show distinctive features (logos, patterns, etc.)
